## Enable GitHub Pages

In the repository, open **Settings → Pages**.

Under **Build and deployment**:
1. Select **Deploy from a branch**.
2. Select branch **main**.
3. Select folder **/(root)**.
4. Click **Save**.

Wait for the Pages deployment to finish, then open the URLs above.
